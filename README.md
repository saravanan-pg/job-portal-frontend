# Job Portal Frontend

A frontend job portal application built using *React* and *Tailwind CSS*.  
This project demonstrates modern frontend practices including component-based architecture, responsive UI design, and scalable project structure.

# Tech Stack
- React (Vite)
- Tailwind CSS
- JavaScript (ES6+)

# Features (in progress)
- Responsive UI layout
- Job listing interface
- Search and filter functionality (upcoming)
- API-driven job data (upcoming)

```bash
npm install
npm run dev
